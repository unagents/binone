# client の接続（鍵の取得と、普段の接続）

client は server との接続を 2 つに分けています。

- **鍵の取得の接続**: server から鍵をもらう接続。初回と、鍵を取り直す時だけ使う。
- **普段の接続**: 持っている鍵で server の GraphQL に繋ぐ接続。起動のたびと、address を変えた時に使う。

## 初回の接続

鍵を持っていない時（初回の起動、または「接続をやり直す」の後）だけ、接続先 server の address を入れる画面が出ます。address を入れて進めると、その address から鍵を取り、鍵と address を保存して接続済みになります。

鍵を渡すのは、server が決めた IP の範囲の端末だけです。範囲の外から試すと、次の案内が出ます。

> この network からは鍵を取れません。server と同じ network から初回の接続をしてください

server に届かない時やその他の失敗は、日本語の 1 行と、確かめる点が出ます。

## 普段の使い方

鍵を持った後は、起動時に入力なしで保存した address に接続します。

設定画面の「server の address」で address を変えられます。変えると、同じ鍵でその address に接続し直します。鍵は address と組で保存され、address を変えても消えません。鍵は一度持てば、server と別の network からでも使えます。

鍵の取得先や IP の範囲は、普段の画面には出しません。

## 鍵が無効の時

変えた先の server がこの鍵を受け付けない（401）時だけ、「この server では鍵が無効です」の案内と「鍵を取り直す」操作が出ます。取り直しは初回と同じ流れで、server と同じ network から行います。範囲の外なら、上の「この network からは鍵を取れません」の案内になります。成功すると鍵が置き換わります。取り直しに失敗した時は、持っている鍵は変わりません。

## 接続をやり直す

設定画面の最下部の「接続をやり直す」は、保存した address と鍵を消して初回の画面に戻します。

## この版でやらない事

鍵の失効、TLS、複数 server の切り替え一覧。
